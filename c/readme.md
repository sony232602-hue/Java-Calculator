# 🧮 Java Calculator

## 📌 Description

The Java Calculator is a console-based application that performs basic mathematical operations including addition, subtraction, multiplication, division, and modulus.

## ✨ Features

* Addition
* Subtraction
* Multiplication
* Division
* Modulus
* Division-by-zero validation
* Interactive console menu

## 🛠️ Technologies Used

* Java
* Object-Oriented Programming
* Scanner
* JUnit

## ▶️ How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA, Eclipse, or VS Code.
3. Compile the Java files.
4. Run `Main.java`.
5. Select an operation and enter two numbers.

## 🧪 Testing

JUnit test cases are included to verify:

* Addition
* Subtraction
* Multiplication
* Division
* Modulus
* Division by zero
